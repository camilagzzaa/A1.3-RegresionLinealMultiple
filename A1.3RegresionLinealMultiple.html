Reporte A1.3 – Regresión lineal múltiple (NASA)

Este reporte muestra el flujo de trabajo para entrenar un modelo de regresión lineal múltiple con el dataset de la NASA.

1) Importación y exploración

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import statsmodels.api as sm

df = pd.read_csv("A1.3 NASA.csv")
print("Dimensiones:", df.shape)
print(df.head(15))

2) Partición de datos 70/30

np.random.seed(42)
msk = np.random.rand(len(df)) < 0.7

X = df[["frecuencia","angulo","longitud","velocidad","espesor"]].values
y = df["presion"].values

X_train, X_test = X[msk], X[~msk]
y_train, y_test = y[msk], y[~msk]

print(X_train.shape, y_train.shape)
print(X_test.shape, y_test.shape)

3) Entrenamiento del modelo

X_train_const = sm.add_constant(X_train)
X_test_const  = sm.add_constant(X_test)

model = sm.OLS(y_train, X_train_const).fit()
print(model.summary())
print(model.pvalues)

4) Variables significativas

alpha = 0.05
pvals = pd.Series(model.pvalues, index=["const","frecuencia","angulo","longitud","velocidad","espesor"])
print(pvals[pvals < alpha])

5) Métricas

y_pred_train = model.predict(X_train_const)
y_pred_test  = model.predict(X_test_const)

# R²
from sklearn.metrics import r2_score, mean_squared_error
print("R² train:", r2_score(y_train, y_pred_train))
print("R² test :", r2_score(y_test, y_pred_test))

# RSE
print("RSE train:", np.sqrt(mean_squared_error(y_train, y_pred_train)))
print("RSE test :", np.sqrt(mean_squared_error(y_test, y_pred_test)))

6) Visualización

plt.scatter(y_test, y_pred_test, alpha=0.6)
plt.plot([y_test.min(), y_test.max()], [y_test.min(), y_test.max()], 'r--')
plt.xlabel("Valores reales")
plt.ylabel("Valores predichos")
plt.title("Validación: Real vs Predicho")
plt.show()
